## 一、定位

**一句话**：小暖带你判断 6 个真实学生的资助情形——「可申请 / 需核实 / 暂不适用」，答完立刻看政策原文。

| 项 | 内容 |
|---|---|
| 载体 | 网页（`game.html`），手机竖屏优先，桌面端可用 |
| 单局时长 | 3–5 分钟，6 关 |
| 目标用户 | 在校学生（尤其新生、班干部、资助委员） |
| 核心价值 | 让「需核实」这一档被真正理解——它不是"不行"，也不是"行" |
| 不用登录 | 扫码即玩，进度只存本地 |

**为什么三个按钮是合理的**：这三档就是系统 `triage_one()` 的输出枚举，答案由程序算，不由文案写。游戏是"练习读懂判定"，不是"另造一套判断"。

## 二、操作方式

### 2.1 界面元素

| 元素 | 位置 | 说明 |
|---|---|---|
| 关卡进度 | 顶部 | 「第 3/6 关」＋进度条 |
| 信任值 | 顶部右 | 3 颗心，答错熄灭一颗 |
| 情景卡 | 主体 | 学生画像（150 字内口语描述）＋ 一句具体问题 |
| 线索按钮 | 情景卡下方 | 「看一眼线索」每关 1 次，用后变灰 |
| 三个选项 | 底部固定 | 可申请 / 需核实 / 暂不适用，垂直排列，高 ≥48px |
| 免责声明 | 页面底部常驻 | 「AI 初判仅供参考，最终以资助部门认定为准」 |

### 2.2 输入方式

| 终端 | 操作 |
|---|---|
| 手机 | 拇指点击大按钮；选项在屏幕下 1/3，单手可达 |
| 桌面 | 鼠标点击；键盘 `1` / `2` / `3` 直接选择，`空格`/`回车` 进入下一关 |
| 无障碍 | 按钮为原生 `<button>`，可 Tab 聚焦；心形信任值带 `aria-label` 文本 |

### 2.3 一次完整操作

```
点「开始闯关」
 → 读情景（可点线索）
 → 点三选一
 → 看揭晓（可点原文卡展开条款全文）
 → 点「下一关」
 → ……第 6 关后进结算
```

## 三、状态切换

七个状态，单向推进，只有失败与重玩会回退。

| # | 状态 | 界面 | 进入条件 | 离开动作 |
|---|---|---|---|---|
| 1 | `boot` | 加载中 | 页面打开 | 题库拉取成功 → `intro`；失败 → `error` |
| 2 | `intro` | 小暖打招呼＋规则＋开始按钮 | 题库就绪 | 点「开始」→ `briefing` |
| 3 | `briefing` | 第 N 关情景卡＋线索按钮 | 上一关结束或开局 | 点任一选项 → `choosing` |
| 4 | `choosing` | 选中项高亮，按钮锁定 | 玩家点选项 | 请求返回 → `reveal` |
| 5 | `reveal` | 对/错＋正确结论＋解析＋原文卡 | 判定返回 | 点「下一关」→ 有剩余关则 `briefing`，否则 `summary` |
| 6 | `summary` | 得分＋星级＋三档正确率＋错题回顾 | 第 6 关结束 | 「再玩一次」→ `intro`；「去 AI 初判」→ 跳转 |
| 7 | `failed` | 信任值归零说明＋已答对题数 | 信任值降到 0 | 「再试一次」→ `intro`（清空本局，保留最高分） |
| — | `error` | 题库加载失败＋重试 | 接口异常 | 点重试 → `boot` |

### 关键转移规则

- `choosing → reveal` 无论对错都进入，**不存在"答错就卡住"**。
- `reveal` 阶段选项按钮禁用，防止连点刷分。
- `failed` 只在 `reveal` 之后判定（先看解析，再告知失败），避免"死得莫名其妙"。
- 刷新页面＝回到 `intro`，本局进度不保留（短局，不做断点续玩）。

```
boot ─→ intro ─→ briefing ⇄ (循环 6 次) ─→ summary
         ↑           ↓
         │        choosing
         │           ↓
         └── failed ← reveal ──(信任归零)
```

## 四、计分规则

| 计分项 | 分值 | 说明 |
|---|---|---|
| 答对一关 | **+150** | 6 关全对 = 900 |
| 全部答对（额外） | **+100** | 完美通关奖励 |
| 使用线索 | **不扣分** | 每关上限 1 条；先查证再判断是鼓励行为，不给惩罚 |
| 答错 | 0 分 | 不扣分（失败由信任值承担，避免双重惩罚） |

**满分 1000**（150×6 + 100）。不设时间分——读政策需要时间，计时会诱导乱选。

线索只给「该看哪一条」的方向提示，不给答案；每关 1 次，用完即灰。

### 星级

| 分数 | 星级 | 称号 | 释义 |
|---|---|---|---|
| 1000 | ★★★ | 政策明白人 | 6 关全对 |
| 750 | ★★☆ | 基本看得懂 | 错 1 题 |
| 600 | ★☆☆ | 还要多看看 | 错 2 题 |
| 失败 | ☆☆☆ | 再来一次 | 信任值归零，未走完全程 |

因信任值上限决定了最多错 2 题，可得分档只有 1000／750／600 三档，不设模糊区间。

### 本地记录

`localStorage` 存三项：最高分、最佳星级、已通关次数。**不落库、不记姓名**。

## 五、失败条件

**唯一失败条件：信任值归零。**

| 项 | 规则 |
|---|---|
| 初始信任值 | 3 点 |
| 扣减 | 每答错 1 关 −1（同一关只扣一次） |
| 归零 | 立即进入 `failed`（在 `reveal` 看完解析后弹出） |
| 失败后 | 可「再试一次」重开本局；最高分保留 |
| 未作答 | 不扣信任值，不自动跳过 |

设计意图：错 1–2 题仍能走完全程（学习优先），错 3 题说明基础概念有偏差，直接结束并建议去看哪几条。相比"错一题就挂"，这个阈值给了容错；相比"无限错也能通关"，它保留了紧张感。

**明确不设的失败条件**：

- ❌ 不倒计时（无超时失败）
- ❌ 不因"答得太慢"扣分
- ❌ 不因刷新/退出判失败
- ❌ 不做连续错误额外惩罚（已有信任值，不叠加）

## 六、六关内容与依据

结论均用真实引擎 `triage_one()` 实测得出，非人工推断。

| 关 | 情景 | 项目 | 结论 | 误解点 |
|---|---|---|---|---|
| L1 | 大一新生，专业排名第一，想申国家奖学金 | 国奖 | 暂不适用 | 成绩再好，年级硬卡二年级及以上 |
| L2 | 大二，成绩优秀，困难认定"还在办" | 励志奖学金 | 需核实 | 认定未出不能下结论；奖项还要学校评审 |
| L3 | 退伍复学读大一，家里没做过困难认定 | 助学金 | 可申请 | 退役士兵走单独口径，不看困难认定 |
| L4 | 湖南生源新生，想申广东新生资助 | 新生资助 | 暂不适用 | 省级项目限广东生源 |
| L5 | 孤儿，已认定特别困难 | 校内学费减免 | 可申请 | 三种身份三选一，但必须特别困难档 |
| L6 | 广东新生，已拿过省里其他专项资助 | 新生资助 | 需核实 | "原则上不重复"是人工确认，不是自动拒绝 |

三档各 2 次，打散顺序，避免"总选中间那个"。

实测记录（2026-11-19）：
```
L1 GJ → not_applicable   L2 LZ → need_check   L3 GZ → eligible
L4 XS → not_applicable   L5 XN → eligible     L6 XS → need_check
```

## 八、后续扩展（二期及以后）

按投入从小到大排列，均已评估合规影响。

### P1｜低成本增强
- **关卡扩到 12 关**：补「材料清单类」「办理渠道类」两类题（现有 5 个项目可覆盖）
- **错题本复盘**：本局错题在结算页可重看解析，不另存
- **分享卡片**：生成"我得了 X 分"的静态图，不含姓名与真实情况
- **键盘与动效打磨**：按钮反馈、卡片翻转入场

### P2｜需要新机制
- **每日一题**：按日期固定抽 1 关，需要题库版本号与日期映射
- **难度分级**：简单（直接给全条件）／困难（有信息缺失、需主动质疑）
- **计时挑战（可选开关）**：默认关闭，开启后 20 秒/关，另算一个榜单，不与主分混算
- **随机出题**：同档位题池随机，需要题量 ≥ 30 才能避免重复

### P3｜需要登录与数据（合规评估前置）
- **班级答题统计**：需落库学生作答记录 → 触碰 I-4（最小化）与 I-5（留痕），须先定脱敏与保留期
- **教师端查看班级薄弱点**：同上，且涉及角色权限扩展
- **个人成长曲线**：需账号绑定，可只存"已答关卡 ID 集合"

### 明确不做（写进设计边界）
- 排行榜公开排名（会诱导背答案，且涉及身份信息）
- 与真实资格判定联动（游戏分数不得影响任何办理结论）
- 虚拟货币、抽卡、养成数值
- 语音朗读（I-4：不存原始录音）

## 九、合规边界

| 约束 | 本策划的处理 |
|---|---|
| I-2 三档只能程序给 | 答案由 `triage_one()` 现算；题面与选项不含结论词；界面禁用"符合/不符合/通过认定" |
| I-1 无条款不出结论 | 每题依据都带 `clause_id`；依据为空则不出结论，改为提示咨询资助中心 |
| I-3 引用系统拼装 | 前端只渲染后端返回的 `quote/doc_no/article_no/偏移`，不自行拼字符串 |
| I-4 信息最小化 | 画像全为合成样例；不存姓名；进度只存 localStorage |
| I-7 原文权威 | 只引用已核文发布的 3 份文件 93 条条款；题干不写未核金额与期限 |
| 免责声明 | 页面常驻＋结算页重复 |
| 技术栈 | 原生 HTML/CSS/JS＋既有 FastAPI，零新依赖、不新建表 |

| 方案 | 效果 | 代价 |
