# 代码目录说明（前后端分层）

整理日期：2026-11-07。源码按“服务端／浏览器端”分成两个顶层目录，运行数据、测试和文档保持独立。

## 1. 顶层结构

```text
资助政策智能体/
├─ backend/                 服务端
│  ├─ app/                  FastAPI 运行包（10 个模块）
│  ├─ tools/                政策采集与知识库工具（5 个脚本）
│  ├─ scripts/              初始化、备份、恢复、隐私扫描（4 个脚本）
│  └─ README.md             后端入口说明
├─ frontend/                浏览器端
│  ├─ login.html            登录／注册
│  ├─ index.html            学生工作台
│  ├─ triage.html           AI 初判
│  ├─ qa.html               政策问答
│  ├─ progress.html         办理进度
│  ├─ review.html           教师审核台
│  ├─ admin.html            管理后台
│  ├─ style.css             四端共用样式
│  └─ README.md             前端入口说明
├─ tests/                   跨前后端联检（接口、账号、页面、版本回滚）
├─ data/                    运行数据（业务库、政策库、上传件、评测集）
├─ docs/                    设计、契约、验证、部署文档
├─ backups/                 备份产物（含整理前源码 zip）
├─ Dockerfile               运行镜像
├─ docker-compose.yml       四端端口映射
└─ README.md / AGENTS.md    项目入口与开发规则
```

## 2. 后端文件职责

| 文件 | 职责 |
|---|---|
| `backend/app/main.py` | FastAPI 路由、四端入口守卫、页面路由、发布／回滚接口 |
| `backend/app/db.py` | 业务库建表、种子、审计；`APP_DB` 可配置 |
| `backend/app/accounts.py` | 注册、审核、登录会话、重置密码、默认管理员 `admin` |
| `backend/app/auth.py` | 从 `fund_session` Cookie 解析当前用户与角色权限 |
| `backend/app/qa.py` | 版本快照检索、问答、引用回点、拒答 |
| `backend/app/agents.py` | 6 个代理协同与 trace |
| `backend/app/ingest.py` | 本地上传政策文档、草稿入库、核文门禁 |
| `backend/app/provider.py` | 三态模型 Provider，默认离线规则模式 |
| `backend/app/identity.py` | 统一身份占位／会话身份适配 |
| `backend/app/logs.py` | 日志脱敏 |
| `backend/tools/policy_collector.py` | 官方栏目页采集、切块、偏移校验 |
| `backend/tools/atomize.py` | 原子条件导入、校验、覆盖、回归 |
| `backend/tools/triage.py` | 确定性判等，输出三档结论 |
| `backend/tools/qa_eval.py` | 50 题问答评测 |
| `backend/tools/fact_support.py` | 原子事实支持机器核验 |
| `backend/scripts/init_db.py` | 幂等初始化业务库 |
| `backend/scripts/backup.py` | 双库备份＋SHA256 清单 |
| `backend/scripts/restore.py` | 恢复＋pre-restore 快照 |
| `backend/scripts/privacy_check.py` | 审计／学生字段明文残留扫描 |

## 3. 前端文件职责

| 文件 | 职责 |
|---|---|
| `frontend/login.html` | 登录／注册；登录成功按角色跳 8000／8001／8002 |
| `frontend/index.html` | 学生工作台：任务统计、最近办理、三个功能入口 |
| `frontend/triage.html` | AI 初判独立页：情况填写、结论、依据条、材料 |
| `frontend/qa.html` | 政策问答独立页：问政策、命中条款回点 |
| `frontend/progress.html` | 办理进度独立页：状态、复核、申诉、材料包／对外报送 |
| `frontend/review.html` | 教师端：待复核、批量初筛、看板、预警；管理员可见申诉裁决 |
| `frontend/admin.html` | 管理端：政策核文、文档入库、注册审核、版本回滚、账号、导出、报表 |
| `frontend/style.css` | 四端共用样式 |

页面不保存角色，不发 `X-Role`／`X-User`；身份只靠后端 HttpOnly Cookie，角色入口由前端显隐＋后端权限双重控制。

## 4. 路径变更对照

| 整理前 | 整理后 |
|---|---|
| `app/*.py` | `backend/app/*.py` |
| `app/static/*.html`、`app/static/style.css` | `frontend/*.html`、`frontend/style.css` |
| `tools/*.py` | `backend/tools/*.py` |
| `scripts/*.py` | `backend/scripts/*.py` |
| `uvicorn app.main:app` | `uvicorn backend.app.main:app` |

## 5. 启动与验证

```powershell
cd <项目根目录>
python -X utf8 -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

容器构建会 `COPY backend`、`COPY frontend`、`COPY data`，容器内工作目录为 `/app`，仍是一个镜像、一个容器、四端端口映射。整理后回归：`smoke 65/65`、`auth 17/17`、`ui 10/10`、`version 10/10`。
