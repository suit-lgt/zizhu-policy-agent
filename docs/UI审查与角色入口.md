# 四端 UI 与角色入口审查

审查日期：2026-11-07。范围：`login.html`、学生端 `index.html`、教师端 `review.html`、管理端 `admin.html`，以及 8000–8003 四端入口。

## 1. 发现并修复的问题

| 问题 | 影响 | 处理 |
|---|---|---|
| 学生端导航有“审核工作台”“管理后台” | 学生误点后跨端，最终落到别的端登录页，多走一步且像出错 | 学生端只保留“学生端”一个当前入口 |
| 教师端导航有“学生端” | 辅导员点了会进入学生页，再被角色守卫送回登录页 | 移除“学生端” |
| 教师端导航常显“管理后台” | 辅导员点了会被 8002 管理页拒绝并回登录页 | 仅管理员／审计员登录后显示 |
| 管理端导航有“学生端” | 管理员点了会进入学生页，再被学生角色守卫送回登录页 | 移除“学生端” |
| 管理端所有账号都显示全部写操作 | 审计员能看到“核对／切块／发布／回滚／停用／重置密码／审批导出”，点击即 403 | 审计员改为只读：隐藏“文档入库”“注册审核”页签，政策、版本、账号、导出只显示数据，不显示写按钮；校级分档隐藏新增表单 |
| 教师端所有账号都显示申诉裁决 | 辅导员和审计员会看到自己无权提交的按钮 | 辅导员完全隐藏申诉面板；审计员只读查看并提示“改判需管理员”；仅管理员显示提交裁决表单 |
| 审计员在审核台看到“通过／退回”“批量通过／退回” | 审计员角色只能查看，点击会被 403 | 审计员改为只读：任务卡不显示复核按钮，批量初筛面板隐藏 |
| 当前生效版本仍显示“回滚到此版” | 点击是无意义操作 | 当前版本显示“当前生效”，历史版本才显示回滚按钮，且回滚前二次确认 |
| 待核文政策也显示“发布”按钮 | 用户点了注定失败，属于无效按钮 | 待核文只显示“核对”和“先核文”提示；核文后才出现“切块／发布” |
| 发布、回滚、停用账号、通过注册、审批导出、批量复核、申诉裁决等一键执行 | 误点会改知识库、改账号状态或产生不可删留痕 | 全部增加二次确认，确认文案写清影响范围 |

## 2. 各端当前可见入口

| 角色 | 默认落点 | 顶部导航 | 写操作 |
|---|---|---|---|
| 学生 | 8000 `/` | 学生端 | 初判、提交复核、申诉、申请导出 |
| 高校教师／辅导员 | 8001 `/review.html` | 审核工作台 | 单条通过／退回、批量初筛；无管理后台、无申诉裁决 |
| 管理员 | 8002 `/admin.html` | 注册审核、任务复核台、管理后台 | 政策核文／发布／回滚、账号、导出审批、报表等全部管理操作 |
| 审计员 | 8002 `/admin.html` | 任务复核台、管理后台 | 只读查看政策、版本、账号、导出、审计、报表；审核台任务只读；无发布、回滚、停用、重置密码、审批、复核按钮 |

跨端原则：

- 管理端点“任务复核台”由服务端 307 跳到 8001，审核台点“管理后台”跳到 8002；页面不再把用户留在错误端口。
- 新账号申请在管理端“注册审核”页签处理，管理端顶部提供直达入口；教师审核台只处理学生初判任务。
- 错误端口的接口仍返回 404，不因为页面跳转而放开权限。
