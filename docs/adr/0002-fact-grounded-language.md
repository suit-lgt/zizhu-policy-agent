# ADR-0002：事实守恒的语言组织（LLM 只组织措辞，不新增事实）

日期：2026-11-15（决定）；2026-11-19 校正状态表述。状态：已采纳并实施（2026-11-15）；真实端点 50 题回归、越界措辞抽样、时延／成本记录与人工语义签认仍 NOT_RUN。

## 背景

本次决定前，工作台在线模式把模型限制为「只返回 `evidence_ids`，正文由程序模板拼装」（`provider.compose_workbench`）。这守住了 I-1／I-2／I-3，但模型几乎不参与语言组织，固定模板无法覆盖口语问法的语义距离，未兑现 `docs/ai-contract.md` 里「模型负责把结论与条款组织成通顺说明」的目标。需要让模型真正组织语言，同时保证它不编造：回答里的事实、结论、引用必须全部来自程序计算，语言措辞可自由变化，事实原子集合守恒。

## 选择

1. 程序确定性生成 **FactPack（事实包）**，模型无权自行检索或挑选条款；只把给定 `facts` 组织成自然语言。每条 quote 类事实带 `anchor`（`version_id:clause_id`）与 `span`，可回点原文。
2. 模型输出严格 JSON：`{answer, claims}`；`answer` 逐句用 `[fact_id]` 锚定，`claims` 是实际用到的事实 id 子集。
3. 机器做 **事实守恒校验** 五层：结构／锚点／事实原子（数字、金额、日期、文号、条款号 ⊆ FactPack）／结论三档守恒／措辞与敏感信息。任一失败不展示，重试 1 次后回退离线模板。
4. 端点继续用 **OpenAI 兼容 `chat/completions`**，沿用 `FUND_LLM_BASE/KEY/MODEL/TIMEOUT` 环境变量，不新增第三方依赖。
5. 三态不变：`offline` 默认（模板，不调模型）；`online` 走事实守恒链路；`mock` 只作自测。页面与导出件仍标 `mode` 与回退原因。
6. 语义是否支持结论仍由资助中心在 `fact_support_review.csv` 逐条签认；机器校验不替代人工核验（I-7）。

## 备选与代价

- 维持「只选 `evidence_id`、正文全模板」：最安全但表达僵硬，模板覆盖有限，未达 ai-contract 目标，故不选。
- 自由生成 + 事后事实核查：依赖额外的核查模型／NLI，超出现有技术栈与依赖约束，且召回不足时无法机器拦截。
- 向量 RAG 语义检索：超出当前 FastAPI＋SQLite 技术栈，需引入本地 embedding；在 H2 未验证前不引入。
- 事实守恒校验的已知盲区：不含数字／文号／日期等标记词的「新事实陈述」（如凭空新增机构名）机器可能漏检；以实体白名单＋人工语义签认兜底，并在真实端点评测中量化残余漏检率。

## 补充边界（2026-11-21）

本决定只约束“事实如何进入语言组织”，不赋予模型计算资格、挑选条款或写数据库的权限。初判六代理仍是纯规则代码；咨询会话若后续要支持“回答时计算”，必须调用确定性判等链 `backend/tools/triage.py`，再把程序结果写入 FactPack，模型不得从自由聊天原文直接判定个人资格。

咨询会话的计算输入、落库字段、隐私边界与三段式查证基线，记录在 `docs/政策咨询工作台迁移设计.md` 第 13 节。本轮只增补文档，未改代码，也未新增在线评测结果；50 题回归、越界措辞抽样、时延／成本记录与人工语义签认仍 NOT_RUN。

## 原文提问持久化（2026-11-21 晚，产品决策变更）

早期边界“原始个人叙述不落库”在**咨询原文**这一项上被本次产品要求覆盖：学生输入原文需作为正式数据持久化，支持新增、修改与刷新恢复。

- 字段映射：`qa_turn.raw_question` 存用户原文；`sanitized_question` 仍存白名单语义重写结果，模型与证据检索只读 `question`，不读 `raw_question`。
- 写入时机：创建轮次 `POST /api/qa/sessions/{sid}/turns` 同时写入原文；修改走 `PUT /api/qa/turns/{tid}/raw-question`，值未变时不写库、不记审计，避免重复写入。
- 读取与迁移：`GET /api/qa/sessions/{sid}` 返回 `turn.raw_question`；旧库由 `qa_sessions.init_schema()` 自动补列，默认空串，不丢原有轮次。
- **隐私影响（需产品/合规知悉）**：原文可能包含姓名、证件号、家庭收入等信息，现在会进入业务库 `data/app.db`。这与本 ADR 早期边界冲突，是本次明确的产品决策，不是无意回归；告知同意、最小保留期与导出范围需另行评估。

## 重议条件

若校验拦截率不足（语义编造漏检）、端点成本／时延超限，或人工语义签认发现支持度问题，重议校验强度或端点选型，不因本轮决定固化。
