# 项目简报：资助政策智能体

状态：草稿（P1 已完成访谈结论，P2 已出首版规格）。负责人：梁广通。更新日期：2026-11-06。

## 用户问题

家庭经济困难的高职学生，在每学期开学前后的资助申报窗口内，需要判断"自己能申请哪些资助、要准备什么材料、去哪里办"。目前靠辅导员口口相传、公众号与同学转告，出现"条款看不懂 → 不敢申请 → 错过申报窗"的损失。

需求依据（**问卷口径，非系统指标**）：校内 833 份 + 基层 300 份共 1133 份；政策接触率 76.0%、价值认可率 73.2%、能自主判定资格仅 23.3%、资格判定环节损耗 68.1%、实际完成申请 25.33%、隐性困难学生 15.61%。来源：《看得见，判不准》调研报告。

## 第一版交付

输入：学生勾选的家庭情况与学籍信息（只含判定必需的原子条件字段）。
输出：可申请项目清单（三档结论）+ 每项的依据条款 + 材料清单 + 办理路径。
确认人：学校资助中心／辅导员（对结论一致性与材料清单准确性负责）。
首个闭环：一名学生完成勾选 → 得到结论与条款 → 导出材料清单，全程断网可演示。

## 范围

本期包含：政策条款库与版本发布、条件原子化、确定性资格初判、依据条与材料清单、政策问答（带引用与拒答）、人工复核与申诉留痕。
本期不包含：资格认定与资金发放、替代任何政务系统、真实学生身份接入、县级（陆河）基层政策口径、方言语音（二期增强）、多校部署。
现实约束：2027 年赛程倒排，2026-12 前完成需求与知识库，2027-02 前核心功能跑通，2027-03 系统完善并公网部署，2027-04 出演示视频与文档；2C4G 单机；个人开发为主。
