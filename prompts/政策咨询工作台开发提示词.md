# 给开发 AI：迁移政策咨询与办理工作台

这是开发指令，不是运行时模型提示词。基础工作台已实现；后续变更须先阅读现有会话、证据、面板和接口实现，避免重建平行链路。

## 可直接复制的任务正文

在当前“资助政策智能体”项目内实施政策咨询与办理工作台。先读 AGENTS.md、README、CONTEXT、docs/design.md，然后读：

- docs/政策咨询工作台迁移设计.md
- .scratch/policy-consult-workbench/spec.md 与 issues/
- docs/adr/0001-policy-consult-workbench.md
- docs/ai-contract.md、docs/data-contract.md、docs/verification.md

核对实际实现：backend/app/qa.py、provider.py、main.py、db.py、auth.py、accounts.py、agents.py、backend/tools/triage.py、frontend/qa.html、triage.html、progress.html、style.css，以及 tests/smoke.py、auth_flow.py、ui_flow.py、version_flow.py、tools/qa_eval.py。

目标：学生可以连续咨询政策、查看可追溯依据和材料步骤，再进入本人初判／进度流程。把同源证据、持久化多轮、分析面板和下一步行动迁移到本项目；不要搬入岗位、课程、教材等问域，不换技术栈。

先输出当前能力／目标增量／本票范围，按六张任务票推进。设计稿中的拟新增端点与文件不是现有事实；先核对目标版本，已有修复不要重复写。

必须遵守：

1. 资格三档由现有规则引擎产生；模型只解释，不能从聊天直接生成新的个人资格结果。
2. 五类意图：条件范围、金额标准、材料、办理流程、本人结果与复核进度。无证据拒答，指代不清澄清。
3. 同轮固定版本与范围，EvidenceBundle 驱动正文、面板、引用和导出。旧引用只能打开该版条款，不查当前表替代。
4. 未核文、未发布或适用性未明的信息不能支撑当前资格／金额结论。学校时限、档位、材料不齐就说明，不猜。
5. 面板由程序生成；命中数不当可靠率。事实支持不只检查文号出现，还要核对数字、结论与具体引用。
6. 保留 online／offline／mock 和校验回退；先发送核验后的证据卡片，正文完整验证后再分块输出，不转发未校验 token。
7. 会话、轮次、证据、导出和 handoff 都校验 owner；新咨询使用 fund_session 登录，不能走请求头身份兜底。
8. 问题／答案持久化前脱敏，不记原始家庭叙述、证件和联系方式；审计用事件 ID、意图、版本、状态。旧 localStorage 历史不跨账号导入。
9. 已有初判／复核／申诉与审计不因会话删除而删除。转初判要确认表单与 consent；聊天按钮不自动提交业务动作。
10. 保留相对 URL、现有子路径部署、四端边界；不照搬其他项目的 Bearer token、绝对根路径或管理员共享会话。
11. 新旧 /api/qa 共用业务层；不得新增另一套游离于发布版的政策库。
12. 轮次有幂等 ID 与显式终态，完成先落库；无 done 的断流不报告成功，重启后的悬挂轮可识别中断。

建议落点：qa.py 继续承载通用问答；按需要拆出 qa_context.py、qa_evidence.py、qa_panel.py、qa_sessions.py；main.py 保持薄路由；db.py 做兼容建表／迁移。文件名是建议，不强制为了拆分而重构。

前端在 qa.html 实现本人记录／问答／办理依据三部分。根据意图只显示有用的范围卡、条款卡、缺项、材料、步骤和动作，手机端可折叠；不为视觉效果堆无意义图表。

运行时提示词草案在 prompts/qa_workbench_v2_draft.md。必须先实现证据契约与验证，再决定接入；当前 provider 仍指向 qa_v1，不要仅改 prompt 文件就宣称新架构完成。

对本票有风险的行为先写失败用例，再做最小修改；在临时库副本和隔离服务验证。政策检索的辅助函数可能写快照，测试前检查环境，不在真实库试错。

按照 spec 的 PC-AC 编号更新 docs/verification.md，命令、环境、证据与未验证项如实记录。既有测试结果是历史记录，不当成这次通过。真实在线模型、人工支持度和学生实操未做就写 NOT_RUN。

不要自动部署、发布政策、导入新政策原文、修改其他业务规则或使用真实学生数据。若授权范围包含部署再按现有部署记录执行，否则交付可验收代码与文档。

最终交付：变化说明、文件清单、验收映射、真实检查结果、剩余限制。先把当前小闭环做完整，不扩展无关功能。
